# Smart Seafood Freshness Indicator (Web Version)

Ứng dụng web đánh giá độ tươi sạch hải sản dựa trên cảm biến màu sắc Anthocyanin (Đề tài Khoa học Kỹ thuật).

## Hướng dẫn đưa lên GitHub:
1. Giải nén file zip này trên máy tính.
2. Tạo một Repository mới trên GitHub.
3. Tải các file (`index.html`, `app.js`, `README.md`) lên kho lưu trữ.
4. Bật GitHub Pages hoặc deploy nhanh qua Netlify để sử dụng trực tiếp trên điện thoại!
